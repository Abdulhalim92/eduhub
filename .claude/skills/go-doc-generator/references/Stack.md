## Что НЕ используем и почему

Иногда важнее зафиксировать осознанный отказ:

- **[Технология X]** — не используем, потому что [причина]. Если возникнет потребность — обсуждать с Tech Lead.
- **GraphQL** — пока используем только REST, GraphQL добавит сложности без явной выгоды на текущем этапе.

## Версионирование зависимостей

- Используем точные версии (`1.2.3`, без `^` или `~`) для критичных зависимостей.
- Обновление мажорных версий — отдельным PR с описанием breaking changes.
- Раз в [квартал] — аудит зависимостей (`npm audit` / `snyk`).
