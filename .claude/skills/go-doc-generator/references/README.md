## Как поддерживать документацию

- Документация — часть кодовой базы. Изменил поведение системы — обнови документацию в том же PR.
- Если документ устарел и нет времени переписать — добавь в начало `> ⚠️ Устарело по состоянию на YYYY-MM, см. [актуальный источник].`
- Новые бизнес-процессы → новый файл в `Workflows/` + ссылка в `Workflows/_index.md`.
