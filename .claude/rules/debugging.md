## Мандат
НЕТ ФИКСУ БЕЗ ROOT CAUSE ИССЛЕДОВАНИЯ. Random fixes порождают новые баги и маскируют первопричину.

## 4 фазы (строго по порядку)

### 1. Сбор доказательств
- Читать полный текст ошибки, не только первую строку (включая stack trace в консоли браузера)
- Воспроизвести стабильно перед любыми изменениями
- Изучить последние изменения в затронутых файлах (`git log -p`)
- Добавить диагностическую инструментацию (console.log, React DevTools) если нужно

### 2. Анализ паттерна
- Найти рабочие примеры аналогичного кода
- Сравнить рабочее с нерабочим — выявить разницу
- Определить зависимости и граничные условия

### 3. Гипотеза
- Одна конкретная теория за раз
- Минимальное изменение для проверки
- Проверять, не предполагать

### 4. Реализация
- Написать failing test воспроизводящий баг (или ручной repro-сценарий в браузере)
- Один целевой фикс — не симптом, а источник
- Verify: симптом исчез, регрессий нет (прогнать тесты + проверить в браузере)

## Стоп-условия
- 3+ неудачных попытки → архитектурная проблема, перепланировать, не продолжать
- Фиксировать не там где проявляется, а там где возникает — трассировать к источнику
