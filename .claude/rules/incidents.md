## Уровни серьёзности
- SEV-1: полная недоступность / потеря данных
- SEV-2: деградация основной функции (поиск, регистрация, профиль учреждения)
- SEV-3: деградация второстепенных функций
- SEV-4: косметика

## Во время инцидента (оперативно)
- Сначала остановить кровотечение (mitigation), потом расследование.
- Фиксировать таймлайн (UTC), решения, кто/что сделал.
- Не логировать PII/секреты при дебаге (контакты детей/родителей — особенно).

## После инцидента (48 часов)
- Написать postmortem по шаблону: `templates/postmortem.md.tmpl` (см. skill `incident-report`)
- У каждого action item: приоритет, владелец, дедлайн.
- Без обвинений, только факты и улучшения системы.

## Чеклист
- [ ] Таймлайн восстановлен
- [ ] Root cause сформулирован и подтверждён данными
- [ ] Добавлены алерты/метрики, чтобы поймать раньше (уровень NFR: uptime ≥ 99.5%)
- [ ] Добавлен/обновлён runbook
