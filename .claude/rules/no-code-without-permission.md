# Не писать код без явного запроса

- Не создавай и не изменяй код (Write, Edit, правки через Bash/sed), пока пользователь явно не попросил или не разрешил.
- Вопрос, обсуждение, анализ, ревью, «как лучше» — это не разрешение. Отвечай текстом, предложи вариант и спроси, делать ли.
- Если задача требует правок — сначала кратко опиши, что и в каких файлах изменишь, и дождись «да» / «делай».
- Разрешение действует только на конкретную задачу. Для следующей правки спрашивай снова.
- Не расширяй объём: не рефакторь, не «улучшай» и не чини соседний код без отдельного разрешения. Заметил проблему — сообщи, не исправляй.
- Чтение, поиск и запуск проверок без изменений файлов разрешены.
