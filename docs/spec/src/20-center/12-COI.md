## CTR-COI. Аналитика баллов

### CTR-COI-010 Аналитика баллов учеников

**Роль:** Admin центра · **Согласование:** допущение (`Q-019`) · **Реализация:** частично · **Экран:** Кабинет центра → Аналитика

Рейтинг учеников по баллам: место, ученик, группа, филиал, баланс баллов, статус. Итоги: число учеников, всего выдано баллов, среднее на ученика, потрачено на оплату, сгорело. Фильтры по группе и диапазону баллов, поиск по имени, постраничный вывод. Администратор филиала видит данные своего филиала, владелец — всех (`BR-038`).

Баллы начисляют только преподаватели за успехи (`LRN-TCH-040`) и автоправила (`CTR-CIN-010`); начисление администратором вручную не предусмотрено (`BR-030`). У заблокированного центра раздел доступен для просмотра (`BR-012`).

**Критерии приёмки**

1. Дано: у центра ученики с разным числом баллов. Тогда рейтинг отсортирован по убыванию баллов.
2. Когда задан диапазон «от 50 до 50». Тогда показаны только ученики с таким остатком.
3. Когда администратор филиала открывает раздел. Тогда видны только ученики его филиала.
