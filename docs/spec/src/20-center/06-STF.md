## CTR-STF. Сотрудники центра

### CTR-STF-010 Сотрудники центра

**Роль:** Admin центра · **Согласование:** допущение (`Q-017`) · **Реализация:** прототип · **Экран:** Кабинет центра → Сотрудники

Список активных сотрудников центра: ФИО, роль (преподаватель, администратор, менеджер), телефон, дата приёма. Фильтр по роли, поиск по имени и телефону, постраничный вывод. Над списком показано использование лимита сотрудников по тарифу («14 из 100»), метки «У лимита» и «Лимит исчерпан».

Администратор добавляет сотрудника (ФИО, роль, телефон) и придумывает ему логин для входа; пароль создаётся автоматически и показывается один раз с кнопкой копирования (`BR-025`). Уволить сотрудника можно только с обязательной причиной: доступ закрывается, логин освобождается. Число активных сотрудников не может превышать лимит тарифа (`BR-023`): при исчерпанном лимите кнопка добавления заменяется пояснением, как освободить место или сменить тариф. Добавление и увольнение записываются в журнал аудита платформы (`PLT-AUD-010`). Состав сотрудников по ролям в профиле центра (`CTR-PRF-010`) считается по этому списку.

**Правила:** `BR-011`, `BR-012`, `BR-023`, `BR-025`.

**Критерии приёмки**

1. Дано: центр на тарифе «Старт» с 4 сотрудниками из 5. Когда добавлен ещё один. Тогда использовано 5 из 5, метка «Лимит исчерпан», добавить следующего нельзя.
2. Когда администратор пытается добавить сотрудника сверх лимита. Тогда добавление отклонено с пояснением про лимит тарифа.
3. Когда сотрудник уволен с причиной. Тогда место освобождается, сотрудник исчезает из списка и из показателей профиля, в журнале аудита есть запись.
4. Когда причина увольнения не указана или короче 5 символов. Тогда увольнение отклонено, сообщение показано под полем.
5. Дано: телефон уже есть у активного сотрудника этого центра. Когда добавляется сотрудник с тем же телефоном. Тогда добавление отклонено.
6. Дано: центр заблокирован. Тогда добавлять сотрудников нельзя (`BR-012`).
7. Когда сотрудник добавлен. Тогда показаны его логин и пароль, пароль после закрытия окна повторно увидеть нельзя и его нет в журнале аудита.
8. Когда выбранный логин уже занят или не соответствует формату. Тогда добавление отклонено, сообщение показано под полем логина.
9. Когда сотрудник уволен. Тогда его логин можно использовать повторно.
