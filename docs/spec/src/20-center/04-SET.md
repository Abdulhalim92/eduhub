## CTR-SET. Настройки центра

### CTR-SET-010 Настройки центра

**Роль:** Owner, Admin центра · **Согласование:** допущение (`Q-029`, `Q-030`) · **Реализация:** план

Настройки делятся на общие для центра и на уровне филиала.

| Настройка | Кто меняет |
|:--|:--|
| Курс обмена баллов, срок жизни баллов | Владелец |
| Шкала оценок (5- или 100-балльная) | Владелец |
| Включённые способы приёма оплаты, ключи эквайринга | Владелец |
| Категории расходов, порог «крупного» сторно, срок подсветки несверенных платежей | Владелец |
| Правила скидок (виды, размеры, сроки) | Владелец |
| Автоправила баллов | Владелец |
| Цены групп, бюджет баллов групп, расписание филиала | Администратор своего филиала |

Каждое изменение записывается в журнал центра («было → стало», актор, время) и видно владельцу (`BR-038`). Ключи эквайринга хранятся зашифрованными и не показываются повторно (`NFR-SEC-040`). Заблокированный центр не может менять настройки (`BR-012`).

**Критерии приёмки**

1. Когда администратор филиала пытается изменить курс обмена баллов. Тогда действие отклонено.
2. Когда владелец меняет срок жизни баллов. Тогда новое значение действует для новых лотов, прежние лоты сохраняют свой срок, в журнале есть запись «было → стало».
3. Когда администратор меняет цену группы своего филиала. Тогда изменение применяется к начислениям следующих месяцев, начисления закрытых месяцев не пересчитываются.
4. Когда администратор меняет цену группы другого филиала. Тогда группа не найдена.
