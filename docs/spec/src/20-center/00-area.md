# Часть B. Центр: расписание, ученики, финансы, зарплаты

Область описывает работу владельца, администратора и кассира центра внутри изолированного контура центра. Данные кассы, прайс-листов и зарплат хранятся только в контуре центра; SuperAdmin видит лишь технические метрики (число активных учеников, статус подписки) — `BR-022`.

Финансовый модуль (`CTR-FIN`, `CTR-PAY`) переработан в версии 2.4; остальные модули перенесены из спецификации v1.2. Критерии приёмки добавляются при проработке каждого модуля; до этого требования имеют статус реализации «план». Исключения: раздел «Материалы и тесты» кабинета центра и подача заявок на публикацию филиалов уже описаны в части A (`PLT-MKT-060`…`PLT-MKT-100`, `PLT-MOD-040`).
