# Часть B. Центр: расписание, ученики, финансы, зарплаты

Область описывает работу Admin центра и Кассира внутри изолированного контура центра. Данные кассы, прайс-листов и зарплат хранятся только в контуре центра; SuperAdmin видит лишь технические метрики (число активных учеников, статус подписки) — `BR-022`.

Модули этой части перенесены из спецификации v1.2 без изменения смысла. Критерии приёмки будут добавлены при проработке каждого модуля; до этого требования имеют статус реализации «план». Исключения: раздел «Материалы и тесты» кабинета центра и подача заявок на публикацию филиалов уже описаны в части A (`PLT-MKT-060`…`PLT-MKT-100`, `PLT-MOD-040`).
