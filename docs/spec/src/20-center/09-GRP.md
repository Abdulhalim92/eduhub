## CTR-GRP. Группы

### CTR-GRP-010 Группы центра

**Роль:** Admin центра · **Согласование:** допущение (`Q-020`) · **Реализация:** прототип · **Экран:** Кабинет центра → Группы, страница группы

Список групп: название, курс, филиал, преподаватель, занято мест из доступных, статус («Активна», «В архиве»). Фильтры по курсу, филиалу, преподавателю и статусу, постраничный вывод. Группа с заполненностью меньше половины отмечена «Мало».

Страница группы показывает курс, филиал, преподавателя, период, систему оценивания (дни и время занятий, длительность, баллы за домашнее задание и за посещение в день, день и баллы за экзамен) и состав: ФИО, телефон, дата вступления, статус. Администратор создаёт и правит группу, добавляет учеников и убирает их из группы. Ученик состоит не более чем в одной группе: добавление в новую переводит его из прежней. Нельзя добавить сверх числа мест, заблокированного ученика или в архивную группу; уменьшить число мест ниже текущего состава тоже нельзя. Преподавателем может быть только действующий преподаватель этого же центра. Убранный из группы ученик остаётся в центре без группы.

**Правила:** `BR-012`, `BR-024`.

**Критерии приёмки**

1. Дано: группа на 2 места с двумя учениками. Когда добавляется третий. Тогда добавление отклонено с пояснением, что мест нет.
2. Когда группа создаётся с датой окончания раньше начала или с преподавателем другого центра. Тогда создание отклонено, ошибки показаны под полями.
3. Когда ученик убран из группы. Тогда место освобождается, ученик остаётся в списке пользователей.
4. Дано: группа в архиве. Тогда менять её состав нельзя.
5. Когда открыта группа другого центра. Тогда она не найдена.
6. Когда у группы время занятия пересекается с другой группой того же преподавателя. Тогда сохранение отклонено (`BR-024`).
