# Нефункциональные требования

Раздел фиксирует то, что уже следует из согласованных требований, и перечисляет показатели, которые ещё нужно утвердить. Утверждённые значения заносятся в таблицу; до этого статус — «к определению».

## NFR-SEC. Безопасность и данные

### NFR-SEC-010 Изоляция данных центров

Данные каждого центра (прайс-листы, платежи, касса, зарплаты) изолированы идентификатором `tenant_id`; SuperAdmin видит только технические метрики (`BR-022`). Согласовано.

### NFR-SEC-020 Неизменяемость журнала аудита

Записи журнала нельзя изменить или удалить; финансовые записи удаляются только сторно (`BR-010`, `SYS-AUD-010`). Согласовано.

### NFR-SEC-030 Режим поддержки

Вход SuperAdmin в кабинет центра всегда отмечен баннером и записывается в журнал (`PLT-CTR-050`). Согласовано.

## К определению

| Показатель | Что нужно решить | Вопрос |
|:--|:--|:--|
| Защита персональных данных детей | Состав хранимых данных, согласия родителей, сроки хранения, требования законодательства страны | `Q-014` |
| Производительность | Целевое время отклика основных экранов, объём центров и пользователей на запуске | `Q-015` |
| Доступность и резервное копирование | Целевой процент доступности, RPO и RTO | `Q-015` |
| Срок хранения журнала аудита | Сколько лет хранить записи платформы и центров | `Q-014` |
| Доступность интерфейса | Требования к адаптивности и специальным возможностям | `Q-015` |
