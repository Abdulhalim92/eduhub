# Часть C. Обучение: журнал, кабинеты, каталог на карте

Область охватывает преподавателя, ученика и родителя, а также единый каталог центров. Модули перенесены из спецификации v1.2 без изменения смысла; критерии приёмки добавляются при проработке модулей. Клиентские платформы для этих ролей (в основном мобильные) описаны в разделе «Клиентские платформы».
